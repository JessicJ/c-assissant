# Web

The local product workspace renders Today, Plans, Inbox, Profile, and Settings. The Plan surface can prepare the current draft through the complete China Country Pack workflow, show concise missing inputs, display the complete saved draft, and confirm that exact version. Settings accepts write-only local Connector configuration without reading secret values back into the browser.

It is not an operations console. The visible connection states are intentionally user-readable, while detailed diagnostics belong to local logs in later phases.
