# Connectors

Normalized provider adapters. The first implemented Connector is Amap.

It currently supports:

- keyword place search;
- driving-route distance and duration facts;
- explicit configuration and provider-failure states.

It does not make recommendations, hail rides, perform payments, book services, or expose API keys to the Web client. Telegram, official-source, weather, and external-handoff Connectors remain future work.
