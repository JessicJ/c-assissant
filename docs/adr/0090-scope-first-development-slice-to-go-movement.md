# Scope first development slice to /go movement

The first development slice of Travel Execution Capability will implement `/go`, Movement Action Cards, Execution Service Catalog, Service Capability Resolution, Local Transport Recommendation, and one Bali movement validation route. Generic nearby food and contextual weather remain in the broader first-slice product scope, but they follow after movement proves the shared execution-card semantics.

## Considered Options

- Build movement, food, and weather together. This would show broader coverage, but it risks delaying validation of the hardest execution path.
- Scope the first development slice to `/go` movement. This creates the smallest demonstrable path for the core execution capability.
