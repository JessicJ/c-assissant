# Require rider confirmation before scooter rental recommendations

Landi will treat scooter rental as a Rider-confirmed Transport Option rather than a default Local Transport Option. The product may include it only when the traveler has explicitly said they can and intend to ride or already have scooter access, because legality, insurance, weather, road conditions, luggage, night travel, and personal riding skill cannot be safely inferred from a destination alone.

## Considered Options

- Recommend scooter rental whenever it is common locally. This may match local travel behavior, but it risks implying safety and legal suitability that Landi has not verified.
- Require rider confirmation before considering scooter rental. This keeps Landi useful for travelers who already plan to ride while protecting the default execution flow from unsafe assumptions.
