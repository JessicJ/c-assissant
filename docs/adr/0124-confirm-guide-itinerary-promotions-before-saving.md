# Confirm guide itinerary promotions before saving

Landi will treat adding guide content, candidate places, priority changes, and itinerary ordering changes as pending itinerary edits until the traveler confirms them in the Web workspace. Selecting add on an unscheduled Guide Card opens a lightweight Placement Selection State first, where the traveler chooses the target day and placement position before a Pending Itinerary Edit is created. Web does not ask the traveler to classify the addition as scheduled or optional during placement; Landi decides whether the resulting draft should become scheduled content, flexible content, or move elsewhere after route and timing checks. This keeps cross-module exploration lightweight while preventing a browsing action from silently changing travel meaning, route checks, reminders, or the next compiled Plan.

Placement Selection State shows available positions with lightweight Placement Advisories for route friction, opening-hour uncertainty, meal timing mismatch, reservation sensitivity, weather fit, or pacing risk. Advisories inform rather than block by default. Blocking is reserved for fixed bookings, explicit traveler constraints, safety constraints, or structural defects that would make the Blueprint unusable.

Ordinary guide additions use a workspace-local edit-and-confirm interaction: the itinerary sequence can highlight the changed placement and the existing edit state provides change/cancel controls until the direct save path exists. They do not require a separate temporary timeline block or mandatory impact summary. High-impact itinerary changes still require impact preview before saving or replanning. Until the direct Blueprint Revision write path is connected, Web may keep the addition as an unsaved local preview and must not route the confirmation through a new conversation turn or imply that the edit has been saved.

Saving immediately on click was rejected because it would make guide browsing feel fast at first, but would blur the line between exploring options and committing itinerary changes.
