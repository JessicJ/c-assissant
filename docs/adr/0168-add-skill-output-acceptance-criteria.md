# Add Skill Output Acceptance Criteria

The planning requirements should include a dedicated Skill Output Acceptance Criteria section for Landi-native planning Skill artifacts. This checklist evaluates whether generated artifacts are ready for Skill Importer normalization and Web workspace rendering.

The criteria cover contract shape, complete Recommended Itinerary content, typed and flexible itinerary blocks, Guide Catalog relationships, informational guide handling, source handling, image optionality, Preparation and Tips relevance, guide writing style, peer option comparison, and claims that must not be made without separate evidence and traveler confirmation.

Keeping these checks only as scattered prose was rejected because the new Skill will need a crisp quality boundary. A dedicated checklist makes later skill design, importer validation, and review easier without prematurely implementing code.
