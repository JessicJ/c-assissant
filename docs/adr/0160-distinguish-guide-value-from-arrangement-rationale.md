# Distinguish guide value from arrangement rationale

Guide Cards and guide detail views may explain why a place, food, local product, or experience is worth considering. This Guide Value Explanation supports browsing, comparison, and traveler taste judgment. It may use a polished, magazine-like Guide Editorial Voice, but should stay grounded in concrete reasons such as architecture, history, flavor, craft, local life, landscape, collection, ritual, or experience style.

Guide Value Explanation is not Per-block Arrangement Rationale. It should not explain why an item was scheduled on a specific day or time, and Web should not treat it as a required schedule explanation field.

Removing all "why it matters" content was rejected because it would turn rich guide material back into a bare place list. Requiring scheduling explanations was also rejected because it would make the itinerary presentation feel heavy and algorithmic. Exaggerated advertising language was rejected because the guide should feel beautiful and trustworthy, not promotional.
