# Make nearby food assistance destination-neutral

Landi will move first-slice nearby food execution out of Country Pack ownership and treat it as Generic Nearby Food Assistance. The capability uses a One-time Location Share and connected place facts to show Ephemeral Nearby Choices and map handoffs without ranking guarantees, reservations, food delivery, payment, or automatic Plan changes.

## Considered Options

- Keep nearby food tied to the China Country Pack. This matches the current implementation, but it conflicts with the destination-neutral Travel Execution Capability.
- Make nearby food generic. This reuses Google Places and Telegram location sharing while allowing the same on-trip behavior to work in Bali and future validation scenarios.
