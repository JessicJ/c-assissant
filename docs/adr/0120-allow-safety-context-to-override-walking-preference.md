# Allow safety context to override walking preference

Landi may override a `walking` preference in first-slice Movement Action Cards when current safety or comfort factors such as distance, night, rain, or heat make walking unsuitable. The card should briefly explain that walking was considered but a safer or more practical option is primary for the current movement.

## Considered Options

- Always honor walking preference. This respects explicit preference but can produce poor on-trip guidance.
- Allow safety context to override it. This keeps recommendations useful and responsible while preserving walking as an alternative when appropriate.
