# Place guide content under Itinerary workspace

Landi will expose the Plan Workspace primarily as Itinerary, Preparation, and Tips, with attraction, dining, shopping, and local signature experiences placed under the Itinerary workspace as schedulable guide sub-branches. This keeps the user's plan-arrangement work centered on the whole trip while preserving rich image-and-text guide material as elements that compose that trip.

Promoting each guide category to a top-level workspace area was rejected because it would make the plan feel fragmented and would separate schedulable travel material from the itinerary where the traveler actually arranges it.
