# Limit first Movement Action Cards to the Next Planned Stop

The first Movement Action Card will route the traveler toward the Next Planned Stop in the current Execution Plan rather than accepting arbitrary ad hoc destinations. This keeps on-trip assistance anchored to approved travel content and avoids expanding the first slice into free navigation, live place search, or implicit plan revision.

## Considered Options

- Support arbitrary traveler-named destinations immediately. This would feel flexible, but it introduces search ambiguity, plan mutation questions, and separate confirmation rules.
- Limit movement to the Next Planned Stop. This matches the execution focus and reuses the approved itinerary as the source of travel meaning.
