# Keep Guide Card copy short

Guide Cards in browsing lists should stay short and scannable. They may show title, local name, optional image or polished text-only teaser, Guide Card Summary, tags, area, itinerary state, compact Source Marker, and state-aware actions.

Full Guide Value Explanation, type-specific comparisons, purchase locations, dining options, experience offerings, practical notes, related material, and source context belong in the shared detail panel rather than the card list.

Putting long guide copy directly into cards was rejected because it would make browsing and filtering harder. The card list should help travelers scan; the detail panel should help them judge.
