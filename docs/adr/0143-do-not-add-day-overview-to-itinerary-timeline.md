# Do not add day overview to itinerary timeline

Landi will not add a separate day overview, daily summary card, or header module above each itinerary timeline. The itinerary timeline should start with the day's concrete Itinerary Blocks.

Weather, pacing, fixed commitments, and contextual cautions should appear through relevant blocks, detail panels, route status, Placement Advisories, or Contextual Tip Surfaces instead of a separate daily overview layer.
