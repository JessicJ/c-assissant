# Keep map as spatial route context

Landi will keep the Itinerary Map focused on spatial understanding, selected-place context, route or sequence review, and route status. It is not the default entrypoint for adding or replacing Guide Items.

Map-first adding and replacement were rejected because they would split the same planning action across multiple surfaces. Guide discovery and adjustment should stay in the Itinerary Explore Panel, shared detail panel, Placement Selection State, and existing edit confirmation path, while the map explains where things are and how the route fits together.
