# Treat unknown luggage as light bag for movement default

The first Movement Action Card rules will treat unknown luggage as a light personal or laptop bag for conservative recommendation purposes. This does not claim the traveler has luggage, but it prevents ride-hail motorbike or scooter rental from becoming the primary recommendation when Landi lacks enough context.

## Considered Options

- Treat unknown luggage as no luggage. This could make motorbike recommendations more common, but it is risky for workation-style travelers.
- Treat unknown luggage conservatively. This keeps recommendations safer while the traveler can still choose alternatives.
