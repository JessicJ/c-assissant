# Support minimal feedback on Execution Action Cards

Landi's first Execution Action Cards will support minimal Execution Card Feedback rather than acting as one-way notifications. Feedback such as "I haven't arrived," "try another option," or "open Plan" may adjust the current execution moment or reveal context, but it does not revise the Trip Blueprint or mutate the Execution Plan without the ordinary review flow.

## Considered Options

- Make cards one-way. This is simpler, but it makes on-trip assistance feel like static notification rather than an execution loop.
- Add broad conversational replanning from card feedback. This is powerful, but it blurs current execution with Plan revision.
- Support minimal feedback. This keeps the loop useful while preserving Plan change boundaries.
