# Do not require stable app links for manual ride handoff

The first Movement Action Card will not require a stable app link or deep link for local ride services. Manual Handoff may be satisfied by naming the service, giving short instructions, and exposing copyable pickup and destination details; a stable app or web link is an enhancement only.

## Considered Options

- Require app-opening links for every local ride service. This would feel smoother, but it depends on provider, device, installation, and region behavior outside Landi's control.
- Allow instruction-based Manual Handoff. This keeps Bali and similar validation scenarios feasible without provider API or deep-link guarantees.
