# Use grounded editorial voice for guide value

Guide Value Explanation may use a polished, magazine-like Guide Editorial Voice. The writing can be visual, textured, and inviting so the Web workspace feels beautiful rather than like a raw database.

The voice must remain grounded in concrete travel value: architecture, history, flavor, craft, local life, landscape, collection, ritual, experience style, or another specific observable reason. It should not rely on exaggerated advertising language, unsupported superlatives, empty praise, or social-media hype.

Guide Editorial Voice is limited to Guide Value Explanation and supporting guide copy. Functional workspace surfaces such as Itinerary Timeline blocks, Preparation Checklist items, Travel Tip Cards, Contextual Tip Surfaces, Option Comparison Rows, route status, and action controls should use Functional Workspace Voice: concise, restrained, and optimized for scanning, judgment, and action.

A purely factual database tone was rejected because guide details need to help travelers imagine and choose. A promotional tone was also rejected because Landi should feel trustworthy and useful, not like an ad.
