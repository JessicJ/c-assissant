# Record Execution Action Cards in Web Inbox

Landi will deliver first-slice Execution Action Cards primarily through Telegram and retain privacy-minimized Execution Card Records in the Web Inbox. This gives the traveler an immediate mobile action surface and a durable workspace history without turning one-time location sharing into saved precise location history.

## Considered Options

- Keep Execution Action Cards only in Telegram. This is simpler, but it loses continuity with the Plan Workspace.
- Record privacy-minimized cards in Web Inbox. This preserves useful execution history while keeping Telegram as the primary interaction channel.
