# Superseded: Use region-aware Global Inspiration Portfolio

Status: Superseded by ADR-0136.

Landi will choose Inspiration Sources through a region-aware Global Inspiration Portfolio instead of assuming one Xiaohongshu-like platform or a China-centered source mix. Destination, traveler language, and content type should influence which social, UGC, review, short-video, image-board, travel-community, maps, merchant, and official sources are considered.

A single global inspiration platform was rejected because travel content ecosystems vary by region and category; using one default would make the generated guide feel narrow, miss local context, and overfit global planning to one market's content habits.
