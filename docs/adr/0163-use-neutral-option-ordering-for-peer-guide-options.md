# Use neutral option ordering for peer guide options

Guide Option Comparison may use Neutral Option Ordering when multiple concrete dining places, purchase places, or experience offerings are shown as peer choices. The ordering can use factual convenience signals such as proximity to the current itinerary, route fit, opening-state confidence, reservation friction, queue risk, timing fit, and source freshness.

Neutral Option Ordering must not present one option as best, recommended, or default-selected. It exists to make a list easier to scan, while preserving traveler choice.

Leaving peer options completely unordered was rejected because it increases browsing effort. Promotional ranking was rejected because it would over-intervene in decisions that depend on traveler taste, budget, convenience, and on-the-day conditions.
