# Do not target mobile Web workspace

Landi's Web workspace is a desktop planning and review surface. It will not design or support a mobile version of the Web workspace for this plan generation and presentation architecture.

The desktop workspace may use higher information density, including visible timeline, map, and explore or detail panel at the same time. This is an intended product property rather than a responsive layout problem.

Mobile Web workspace design was rejected because it would force the itinerary, map, guide exploration, details, preparation, and tips into a constrained layout that changes the product shape. On-trip mobile assistance can remain in execution channels such as messaging or action cards; the Web workspace should stay focused on richer desktop review and adjustment.
