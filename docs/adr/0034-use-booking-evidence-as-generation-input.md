# Use Booking Evidence as Generation Input

Booking confirmations are collected as Booking Evidence during the Planning Session and converted into Booking Constraints for the Planning Proposal and Blueprint Generation, rather than being treated only as post-generation reservation records. This preserves flights, lodging, rental cars, tickets, and other real-world commitments as itinerary-shaping facts while still allowing the resulting bookings to be linked to the compiled Plan for reminders, routes, and execution.
