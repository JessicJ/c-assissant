# Do not show source markers on timeline blocks by default

The Itinerary Timeline will not show Source Markers on each block by default. Timeline blocks should remain compact, focused on time, title, type, place or area, and short status. If a block has a schedule-critical fact that needs attention, such as a fixed booking, reservation need, or recheck state, the timeline should express that as status text rather than a source marker.

Source transparency remains available through Guide Cards, images, Tips, itinerary details, and shared detail panels. Selecting a timeline block can open details where source markers or source disclosures are appropriate.

Showing source markers directly on every timeline block was rejected because it would make the time-ordered plan look like a citation surface instead of a readable travel schedule.
