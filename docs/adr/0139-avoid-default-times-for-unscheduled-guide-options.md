# Avoid default times for unscheduled Guide Options

Landi will not attach a default day, time, or visible replacement-type label to Guide Items that are not already part of the Recommended Itinerary. Unscheduled guide material may explain suitable contexts, real constraints, and concrete places, but the traveler chooses when to place it through a pending itinerary edit. Any compatibility with meal, shopping, attraction, experience, or flexible blocks remains internal until the traveler starts an add/replace action.

Default day or time suggestions for every optional item were rejected because they make backup material look like omitted schedule work and can pressure the traveler toward changes Landi has not actually integrated into the recommended route.
