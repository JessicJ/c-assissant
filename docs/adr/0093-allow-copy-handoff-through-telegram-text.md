# Allow Copy Handoff through Telegram text

The first Movement Action Card may satisfy Copy Handoff by rendering pickup and destination details as long-press-copyable Telegram message text. A one-click clipboard button is not required because ordinary Telegram bot buttons may not be able to write to the traveler's clipboard.

## Considered Options

- Require true one-click copy controls. This would be convenient, but it may depend on client-specific UI capabilities outside Landi's control.
- Allow copyable text. This is reliable enough for the first slice and preserves Manual Handoff feasibility.
