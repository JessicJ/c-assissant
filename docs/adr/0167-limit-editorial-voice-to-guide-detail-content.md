# Limit editorial voice to guide detail content

Guide Editorial Voice should be used only in Guide Value Explanation and supporting guide copy. It should not be used in Itinerary Timeline blocks, Preparation Checklist items, Travel Tip Cards, Contextual Tip Surfaces, Option Comparison Rows, route status, or action controls.

Those functional surfaces should use Functional Workspace Voice: concise, restrained, and optimized for scanning, judgment, and action.

Letting magazine-like writing spread across the workspace was rejected because it would blur the jobs of each surface. Guide details can invite and explain; functional surfaces should help the traveler read, compare, and act quickly.
