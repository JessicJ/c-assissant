# Keep attractions as concrete places

Landi will model attraction Guide Cards as concrete Attraction Places that reference Place Identity directly. Attraction themes, such as architecture, rainy-day museums, first-time landmarks, neighborhoods, or family-friendly stops, are browsing groups rather than separate schedulable content objects.

Splitting attractions into a theme layer and an offering or place layer was rejected because attractions are usually already concrete places. Theme grouping is enough for discovery, while direct Place Identity keeps adding, locating, routing, and source status simpler.
