# Start Travel Execution with on-trip assistance

Landi will start the destination-neutral Travel Execution Capability with On-trip Execution Assistance instead of pre-departure preparation. This keeps the first implementation focused on current movement, food, weather, departure timing, and external handoffs, while avoiding a return to destination-specific guide or Regional Pack work.

## Considered Options

- Include pre-departure preparation such as entry rules, tourist taxes, driving permits, SIMs, insurance, and payment setup. These are valuable, but they quickly require destination-specific authority, applicability, and evidence handling.
- Start with on-trip assistance. This better matches Landi's existing route, weather, food, reminder, location-sharing, and handoff capabilities and is easier to validate across multiple destinations.
