# Limit Bali service catalog to core Manual Handoffs

The first Bali Service Catalog entries will include Grab, Gojek, Bluebird, and private driver Manual Handoffs only. Scooter rental remains a Rider-confirmed Transport Option, but Landi will not recommend specific scooter rental vendors in the first movement slice.

## Considered Options

- Include rental vendors and broader local services. This could feel more complete, but it adds vendor curation and safety scope.
- Limit the catalog to core manual handoffs. This is enough to validate local movement without expanding into vendor recommendation.
