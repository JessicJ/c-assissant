# Render flexible blocks with rough time labels

Flexible Itinerary Blocks should remain ordered inside the Itinerary Timeline and render with localized Rough Time Labels rather than empty time cells or invented precise start times. Examples include around lunch, flexible afternoon, and optional evening.

Exact times should be reserved for fixed bookings, opening-hour-sensitive visits, transport commitments, and blocks where the planned start time materially affects execution.

This keeps the timeline readable as a day sequence while avoiding false precision for meals, shopping, local experiences, rest, and exploratory stops.
