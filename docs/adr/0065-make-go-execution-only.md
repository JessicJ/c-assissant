# Make /go execution-only

Landi will allow `/go` only against the current Execution Plan, not against an unapproved Draft Plan. Movement Action Cards can guide real on-trip behavior and offer external handoffs, so they require the same execution authority boundary as reminders and monitoring rather than treating draft itinerary content as actionable.

## Considered Options

- Allow `/go` from Draft Plans for preview. This could help users inspect routes, but it blurs review with execution and may encourage acting on unapproved content.
- Make `/go` execution-only. This keeps movement assistance aligned with Plan activation.
