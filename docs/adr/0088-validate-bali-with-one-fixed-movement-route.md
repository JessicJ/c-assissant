# Validate Bali with one fixed movement route

The Bali Validation Scenario may use one fixed movement route from a lodging anchor to the Next Planned Stop rather than a complete multi-day itinerary. The purpose is to prove the Travel Execution Capability chain, including `/go`, Next-stop Selection, One-time Location Share, local transport recommendation, service capability resolution, and Manual Handoff behavior.

## Considered Options

- Validate with a full Bali itinerary. This would feel more complete, but it tests planning content more than the execution capability.
- Validate with one fixed movement route. This is enough to prove the core first-slice movement path.
