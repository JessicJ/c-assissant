# Use ranked action sets in Movement Cards

Movement Action Cards will present a Recommended Action Set rather than a single transport button. A primary Local Transport Recommendation plus useful alternatives lets Landi explain context-sensitive tradeoffs such as rain, night travel, distance, luggage, party size, and route duration while still leaving the final external action to the traveler.

## Considered Options

- Show only one chosen transport action. This is simpler, but it hides uncertainty and reduces Landi to a link launcher.
- Show a ranked action set. This better expresses Landi's judgment while preserving traveler control.
