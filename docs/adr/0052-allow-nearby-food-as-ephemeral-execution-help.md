# Allow nearby food as ephemeral execution help

The first Nearby Food Action Card may show restaurants or food options discovered from a One-time Location Share even when they are not part of the approved itinerary. These options remain Ephemeral Nearby Choices and do not change the Trip Blueprint or Execution Plan unless the traveler later makes an explicit revision.

## Considered Options

- Restrict nearby food to planned itinerary places only. This would keep execution tightly anchored to the Plan, but it would miss a common on-trip need where eating is opportunistic.
- Allow ephemeral nearby food choices. This keeps the Plan stable while still helping the traveler act in the moment.
