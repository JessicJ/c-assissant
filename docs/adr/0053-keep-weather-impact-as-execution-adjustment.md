# Keep weather impact as execution adjustment

The first Weather Impact Action Card will recommend temporary Execution Adjustments rather than automatically changing the Trip Blueprint or Execution Plan. Weather can change how the traveler should act now, but replacing itinerary content remains a separate reviewable revision or replacement flow.

## Considered Options

- Let severe or inconvenient weather automatically reorder the itinerary. This could feel proactive, but it would silently mutate approved travel content.
- Keep weather impact as execution adjustment. This gives useful current guidance while preserving Landi's review boundary for real Plan changes.
