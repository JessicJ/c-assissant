# Use Telegram as the first Execution Channel

Landi will deliver the first on-trip Execution Action Cards through Telegram, while the existing Web surface remains limited to planning, Plan display, map context, and configuration. The first slice should not add new Web pages, Web configuration fields, or Web execution controls because Telegram already supports traveler messages, explicit location sharing, reminders, and URL buttons.

## Considered Options

- Make Web and Telegram equal first-class execution surfaces immediately. This would increase coverage, but it would duplicate interaction work before the card semantics are proven.
- Use Telegram first. This reuses the strongest existing on-trip affordances and avoids expanding Web beyond its existing Plan review, spatial context, and configuration responsibilities.
