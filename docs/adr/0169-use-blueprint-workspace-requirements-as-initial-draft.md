# Use Blueprint Workspace requirements as initial draft

`docs/blueprint-workspace-generation-requirements.md` is now the initial PRD-style requirements baseline for the Landi-native planning generation and Web workspace presentation redesign.

The draft captures the agreed direction for replacing the `interactive-trip-planner` product shape with Landi-native structured Blueprint output, Skill Importer normalization, Plan Compiler boundaries, and Web Plan Workspace rendering with Landi components. It includes the settled content model, guide presentation rules, source strategy, image optionality, timeline behavior, preparation and tips boundaries, and Skill Output Acceptance Criteria.

Continuing to treat the document as an open-ended grill log was rejected because the core decisions have converged. The next stage should use this draft as the artifact to review, refine, and eventually split into implementation work only after explicit approval.
