# Show sources through unobtrusive markers

Landi will show guide and image provenance through small Source Markers on cards, images, tips, and itinerary details, revealing inspiration and evidence references on hover, focus, or tap. Itinerary Timeline blocks do not show Source Markers by default; they use compact status text for schedule-critical facts such as needs recheck, fixed booking, or reservation required. This keeps the default plan presentation clean while preserving source transparency and the distinction between inspiration and verified evidence.

Always-visible citation blocks were rejected because they would make the guide feel cluttered and overly academic; hiding provenance entirely was rejected because travelers still need to understand where inspiration and factual checks came from.
