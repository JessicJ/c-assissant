# Include short external confirmation reminder

Movement Action Cards that hand off to another ride or navigation service will include a short reminder that the traveler must confirm pickup, price, vehicle, and payment in the external app before requesting. The reminder preserves Landi's External Action boundary without turning each card into a long disclaimer.

## Considered Options

- Omit the reminder for a smoother card. This risks implying Landi has verified or completed the external action.
- Add a long legal disclaimer. This is safer on paper, but it harms on-trip usability.
- Use a short reminder. This keeps the boundary visible and usable.
