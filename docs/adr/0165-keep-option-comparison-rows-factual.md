# Keep option comparison rows factual

Option Comparison Rows should show Comparison Facts: comparable, traveler-useful facts or explainable signals such as location, distance, route fit, hours, source state, price or effort, reservation need, queue friction, dietary fit, timing fit, or accessibility.

Subjective promotional phrases such as "must-visit", "super popular", "hidden gem", or social-media hype should not appear in comparison rows. If subjective appeal is useful and sourceable, it belongs in Guide Value Explanation or supporting guide copy.

This keeps the comparison area calm and decision-oriented. The row helps travelers compare; it should not try to sell one option.
